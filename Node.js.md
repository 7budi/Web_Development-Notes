## What is Node.js?
- Node.js is a JavaScript runtime that lets you run JavaScript code outside of a web browser typically on a server.
- "An asynchronous event-driven javascript runtime, Node.js is designed to build scalable  network application." - according to Node.js.
- NodeREPL(Read Eval Print Loop): is a computer environment where user inputs are read and evaluated, and then the results are returned to the user.
