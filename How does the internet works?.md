The **internet** is a network that connects different computers(by large wires) and transfers information from a source to a destination through wired and wireless communication channels.

**Server**: is a computer which works 24/7 to serve any data that is requested when trying to access a website, it is like a giant library.

**Q1) If a serve is like a giant library that store all the website, how is it able to find the one you actually wants?**
**ANS:** When one search anything in the browser that message is sent to the ISP(Internet service provider, this are the people who pay to access the internet, the ISP will relay that message to DNS(Domain Name System)server, the DNS server is like a phone book that have the IP address of every website which can find the one that is being searched.
